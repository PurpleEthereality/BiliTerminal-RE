弹窗实现还原稿 v3

这一版不是「设计构想」，而是按当前代码逐值还原的渲染预览 —— 用来核对你看到的和设计稿是不是同一件事。

上一版设计稿 dialog-redesign-v2.html 是「要改成什么样」； 本稿是「代码现在实际画成什么样」。取值来源： colors.xml 的 on_surface_terminal/terminal_surface、 dimens.xml 的 card_round/dialog_*、 dialog_background.xml 的描边、两个 layout/item_dialog_terminal.xml。

1 · 上一版「外圈那一道线」的成因

描边画了两层。上一版代码里：
  1. 主题 overlay 的 android:background=@drawable/dialog_background 给窗口画了一层圆角+描边；
  2. TerminalDialog.kt 又对 content 调了一次 setBackgroundResource(dialog_background)，画了第二层。
两层之间还隔着 dialog 默认的 padding，于是看起来就是「弹窗外面又套了一圈线」。 更糟的是描边取的是 ?attr/colorPrimary —— 经典终端下就是 #FF6699 荧光粉， 在深色底上非常扎眼。
已修：去掉 content 那一层，只保留窗口背景一层；描边色从 colorPrimary 改为 colorOnSurface @ 32%（即 #EBE0E2 半透明白），与设计稿方案 B 的 rgba(254,254,254,.32) 对齐。下面所有预览都是修好之后的形态。

6 · 关于圆角：6dp 还是 12dp

dimens.xml 里 card_round=6dp 是「方角」档的值，card_round_large=12dp 是「圆角」档的值 —— 用户在「外观设置」里切换的那一项。弹窗若钉死 12dp，用户选了「方角」仍会看到圆角弹窗，与设置项语义直接打架。 所以代码里弹窗跟随 card_round。

7 · 怎么在真机上看到它

已 assembleDebug 通过（BUILD SUCCESSFUL）、 单测 425 项全过。APK 在 app/build/outputs/apk/debug/。

注意：我用 adb install 尝试装到已连接的 V2229A 上时，被设备侧拒绝 （INSTALL_FAILED_ABORTED: User rejected permissions）， 关闭安装校验后仍被拒 —— 这是 Vivo 的系统限制，需要在手机上手动确认或调整「安装未知应用」权限。 所以真机目视确认尚未完成，上面所有预览是按代码取值在 HTML 里等价还原的。
